# SECTOR 1 — бронирование игровых станций

Интерактивный сайт компьютерного клуба с выбором игровых мест на схеме помещения, расчётом стоимости аренды и возможностью оформлять и отменять учебные бронирования.

## Технологии

- HTML5
- CSS3
- JavaScript (ES Modules)
- localStorage

## Как запустить локально

1. Скачайте и распакуйте проект.
2. Откройте папку проекта в Visual Studio Code.
3. Убедитесь, что все файлы проекта находятся на своих местах.
4. Установите расширение **Live Server**.
5. Откройте файл `index.html` через Live Server.

Установка дополнительных библиотек и настройка сервера бронирований не требуются.

## Функции JavaScript

- Формирование интерактивной схемы клуба и списка станций на основе единого массива данных.
- Переключение между схемой и списком с сохранением текущего выбора.
- Отображение свободных, выбранных и занятых станций с помощью цвета, текста и символов.
- Фильтрация по категории, максимальной цене и доступности мест.
- Выбор одного или нескольких свободных компьютеров, удаление отдельных станций и очистка выбора.
- Отображение характеристик и тарифов выбранных компьютеров.
- Выбор пакета игрового времени или ручной ввод количества часов.
- Автоматический расчёт общей стоимости и проверка введённых значений.
- Создание единой брони с уникальным номером и защитой от повторного подтверждения.
- Отображение бронирований в виде цифровых пропусков.
- Сохранение и восстановление записей через localStorage.
- Отмена брони с освобождением всех связанных станций.
- Автоматическое обновление статистики доступности игровых мест.
- Обработка ошибок хранилища и сброс учебных бронирований с подтверждением.

Интерфейс адаптирован для мобильных устройств и поддерживает управление с клавиатуры.

## Игровые зоны

В клубе предусмотрено 12 игровых станций, две из которых изначально заняты.

| Характеристика | Standard | VIP |
| --- | --- | --- |
| Количество станций | 8 | 4 |
| Тариф | 150 ₽/час | 250 ₽/час |
| Видеокарта | RTX 4060 | RTX 4080 |
| Оперативная память | 16 ГБ | 32 ГБ |
| Частота обновления монитора | 144 Гц | 240 Гц |
| Периферия | Механическая клавиатура | Премиальная периферия |

На схеме также обозначены проход, вход, ресепшен и зона отдыха. Все игровые станции имеют одинаковый размер.

## Пакеты игрового времени

- **START** — 1 час.
- **SQUAD** — 3 часа.
- **MOVEMENT** — 5 часов.
- **MARATHON** — 12 часов.

Продолжительность также можно задать вручную: от 1 до 12 целых часов. Пакеты предназначены для быстрого выбора времени и не изменяют почасовые тарифы.

Общая стоимость рассчитывается как сумма почасовых тарифов выбранных компьютеров, умноженная на продолжительность игровой сессии.

## Структура проекта

- `index.html` — структура страницы, навигация и элементы интерфейса.
- `css/style.css` — визуальное оформление и адаптивная вёрстка.
- `js/data.js` — данные игровых станций, тарифы и характеристики оборудования.
- `js/app.js` — логика выбора, фильтрации, расчёта стоимости и управления бронированиями.
- `js/storage.js` — сохранение, восстановление и проверка данных в localStorage.
- `README.md` — описание проекта и инструкция по запуску.

## Ограничения учебного проекта

Учебное демо: бронирования сохраняются только в этом браузере.

Реальные платежи, регистрация и серверная часть отсутствуют. Бронирование не привязано к календарной дате: выбранные компьютеры считаются занятыми до отмены брони. Данные не синхронизируются между устройствами, а штрихкод цифрового пропуска является декоративным элементом.

## Публикация сайта

Проект можно разместить на GitHub Pages.

1. Создайте публичный репозиторий GitHub и загрузите файлы проекта в его корневую папку.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Нажмите **Save** и после публикации откройте полученную ссылку.
5. Проверьте выбор станций, расчёт, сохранение после обновления страницы и отмену брони.
